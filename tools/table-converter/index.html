使用：粘贴后会自动转换；可直接修改右侧文字，再点击顶部按钮复制。在 Chrome 中拖动跨过多个单元格，可框选连续矩形区域；高亮后按 Ctrl+C 进行无格式复制，按 Esc 取消。「复制到 Word」只保留表格与合并结构；「复制到 Excel」只复制纯数据。两者均不携带字体、边框、字号、底色或内边距。
使用：从 Word 或 Excel 复制表格并粘贴到左侧，右侧自动生成可编辑预览；确认后点击「复制到 draw.io」，再到 draw.io 画布按 Ctrl+V。支持合并单元格、中文和多个表格；样式不会带入 draw.io。
