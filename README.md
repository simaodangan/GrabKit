# 随手用 · GrabKit

以独立 HTML 页面作为工具模块，Electron 提供窗口与原生能力，无需前端构建服务。

## 启动

```sh
npm install
npm start
npm run check
```

如果已有依赖目录但缺少 Electron 运行程序，可运行 `npm rebuild electron`。全局快捷键 **Ctrl+Shift+Space** 唤起工具箱；占用时在控制台提示。关闭窗口后程序留在系统托盘，从托盘菜单退出。

## Windows EXE 安装包

双击根目录的 `Release.bat`，将自动安装依赖、检查文件并生成 Windows 安装包，成功后打开 `dist` 文件夹。需先安装 Node.js（含 npm），首次打包需要联网下载依赖；打包前请从系统托盘退出正在运行的随手用。失败时窗口会保留错误信息。

也可以手动运行：

```sh
npm install
npm run check
npm run pack:win
```

输出位于 `dist/GrabKit-Setup-<版本号>-x64.exe`，例如 `GrabKit-Setup-0.1.0-x64.exe`。安装后的主程序为 `GrabKit.exe`，卸载程序为 `Uninstall.exe`。直接分发此 EXE 即可，用户可通过中文安装向导选择安装位置，并创建桌面和开始菜单快捷方式。支持从 Windows 设置卸载，卸载时保留用户配置。版本号读取 `package.json` 的 `version`，打包不会自动递增。

安装向导在选择安装位置后显示「安装选项」：开机自动启动、创建桌面快捷方式、在开始菜单创建文件夹，三个选项默认勾选，均可取消。开始菜单文件夹内包含主程序和卸载程序快捷方式。重新安装时按本次选择设置；开机自启动也可在应用「设置 → 开机自启动」中关闭，卸载时清理启动项和快捷方式。开机启动仅显示系统托盘图标，手动打开、双击托盘或使用 Ctrl+Shift+Space 时显示主界面；托盘创建失败时显示主界面。直接运行免安装目录不会自动开启自启动。

关闭 ASAR 归档以支持截图功能调用随应用附带的 PowerShell 脚本。`dist/win-unpacked/` 是打包过程中生成的应用目录，正式分发使用 Setup EXE。重新打包前请退出该目录中运行的程序。

## 添加独立工具

在 `tools/工具名/` 下创建 `index.html`、可选 `script.js` 和 `tool.json`：

```json
{
  "id": "my-tool",
  "name": "我的工具",
  "category": "桌面效率",
  "description": "工具用途说明",
  "icon": "▦",
  "color": "purple",
  "keywords": "搜索关键词",
  "entry": "index.html"
}
```

重启自动发现，分类同步生成，无需修改主界面。ID 必须唯一，仅允许小写字母、数字和连字符；入口必须是当前工具目录内的 HTML。每个工具复用一个独立窗口，不同工具可同时打开。页面 CSP 可参考现有工具。

此机制用于本地可信工具，不是第三方插件权限沙箱。当前仅保留屏幕截图和 GPT 论文公式转 Word 两个工具。

## 原生接口

通过 `window.desktop` 调用：

| 接口 | 用途 |
| --- | --- |
| getVersion() | 版本信息 |
| listTools() | 工具元信息 |
| openTool(id) | 打开或唤回工具窗口 |
| clipboard.readText() / clipboard.writeText(text) | 文本剪贴板 |
| files.openText() | 选择文本文件，返回 {name, content} 或 null |
| files.saveText(text) | 选择路径并保存，返回是否保存 |
| setAlwaysOnTop(boolean) | 当前窗口置顶 |
| captureScreens() | 屏幕截图数组 {id, name, dataUrl} |

文件读写经系统选择框获取路径，不接受页面传入任意路径。读取限制 10 MB，写入限制一千万字符。IPC 校验来源窗口，页面启用上下文隔离与沙箱，禁用 Node.js 直连、页面导航及新窗口。

## 当前范围

- 已实现工具导航、搜索、分类、收藏、最近使用、窗口复用、托盘、全局快捷键、窗口置顶。
- 截图主界面提供「开始截图」，以及默认勾选的「包含光标」「隐藏窗口」。Ctrl+Shift+R 启动截图，原 Ctrl+Shift+W 快捷键也保留并启动相同流程。截图模块仅在打开截图工具后初始化，准备完成后启用按钮；关闭截图工具时注销快捷键并停止后台模块（已有贴图仍可操作）。启动后冻结整个桌面及窗口位置并压暗显示，鼠标所在窗口恢复原色并显示边框；单击松开后截取窗口，按住拖动则切换为区域截图，区域恢复原色，松开完成。截图始终从同一张冻结画面裁剪，保留原来的遮挡，不重新抓取窗口
内容。提示框跟随鼠标，优先显示在右下方，靠近右侧时移至左侧、靠近底部时移至上方；显示放大预览、坐标、尺寸、HEX 和 RGB，不显示操作提示。预览默认放大 4×，可在截图工具界面通过滑块选择 2×～8×（步长 1×），按钮和快捷键均使用当前设置。十字辅助线根据局部背景亮度切换黑白，不写入截图。支持跨屏选区，Esc 或右键取消。鼠标按键独立检测，首次点击或拖动不依赖截图层获得焦点。隐藏窗口仅控制截图工具自身，不会隐藏其他贴图或工具窗口，完成或取消后恢复。Windows 使用原生屏幕快照并按选项保留冻结时的鼠标光标。截图默认按原始位置和 100% 尺寸生成独立无标题贴图（按所在屏幕缩放比例换算），可拖动、等比例缩放，同时打开多张；Ctrl+C 或右键「复制图片」复制原图。右键使用系统原生菜单，可设置置顶、点击「透明度…」打开独立滑块面板（10%～100%，步长 1%），实时调整并保留当前值、选择无边框/较细/中等/较粗（0/2/3/4 像素）、重置尺寸为 100%、保存 PNG、关闭当前图片或确认后关闭所有图片。边框按 Windows 实际客户区物理像素绘制；切换边框时仅调整外沿，图片内容的位置和缩放保持不变。默认置顶、中等边框（3 像素）；Esc 取消框选或关闭贴图。最小化窗口或受保护内容可能无法捕获，请先还原目标窗口。保存和复制不包含显示边框和透明度效果。选项在当前运行期间生效，重启后默认勾选。
- GPT 论文公式转 Word 已接入用户提供的 HTML 工具：支持正文、基础 Markdown 与 LaTeX 公式转 MathML，预览后复制到 Word；不是直接导出 .docx。MathJax 3.2.2 作为本地依赖安装，运行不联网。实际粘贴效果取决于 Word 版本和粘贴选项。
- 工具输入默认不持久化、不联网；收藏与最近使用仅在本机保存工具 ID。
- 已配置 Windows x64 EXE 安装包；签名、自动更新尚未配置。

检查脚本不替代 Windows 实机验证；托盘退出、快捷键冲突、多屏截图、文件取消及未保存关闭流程仍需实机验证。

## 导航与窗口控制

托盘菜单的「所有工具」列出当前工具，点击即可直接打开。一级菜单仅有「窗口」和「帮助」：「窗口」包含窗口置顶和设置；「帮助」包含刷新页面、开发者工具和关于。「帮助 → 关于」显示软件图标、编辑者 AI、版本号 0.1 和编译日期。

EXE 打包采用 electron-builder 时，package.json 的 beforePack 钩子会自动生成 build-info.json，将打包当日的北京时间日期封装进应用。编译日期不会随启动时间变化；开发运行显示「尚未编译为 EXE」。

主界面左上角 ☰ 可隐藏或显示侧栏，自动记住选择。标题栏与菜单合并为一行：左侧为窗口名称，右侧为菜单、最小化、最大化/还原和关闭。点击右侧「菜单 → 窗口 → 窗口置顶」控制当前窗口，快捷键 Ctrl+Shift+T。标题栏由 preload 统一注入，工具页面无需重复实现。







软件图标统一来自 shared/app-icon.svg；scripts/generate-icons.py 可生成界面与托盘使用的 PNG，以及窗口和 EXE 打包使用的多尺寸 ICO（需要 Pillow）。
